# MediAgent Datasets

This directory contains datasets and references used by the MediAgent system.

## Dataset Categories

- Synthea - Synthetic patient records
- DDXPlus - Differential diagnosis
- PubMedQA - Biomedical question answering
- BioASQ - Biomedical QA
- RxNorm - Drug normalization
- MIMIC-IV-ED - Emergency department data
- SNOMED CT - Clinical terminology
- UMLS - Medical terminology mapping
- OpenStreetMap - Healthcare facility locations
